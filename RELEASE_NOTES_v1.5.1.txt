TechMedic v1.5.1 Release Notes

Focus: one-click diagnostic bundle export.

New:
- Active cases with at least one completed turn show a "Download diagnostic bundle" button.
- One ZIP captures the screen-equivalent current case output, complete conversation,
  latest LLM structured state, raw Jev decision, controlled research trace, safety
  result, timing telemetry, case metadata, and all raw saved turns.
- A combined Markdown report is included so a reviewer can usually open one file first.
- The exporter does not include .env or API keys.

This is a focused usability update to v1.5; the controlled-research and v1.4.x
lifecycle behavior are otherwise unchanged.
